# 🎮 Motor de Videojuego 2D (IA Assisted)

## 📌 Introducción

Este repositorio contiene el desarrollo de un motor básico de videojuego 2D realizado en Java, como parte de un proyecto académico.

El objetivo principal del proyecto es implementar la lógica interna de un videojuego sin interfaz gráfica, simulando un entorno de cuadrícula con entidades, colisiones y control de estados del juego.

---

## 📁 Estructura del proyecto

* `main` → versión estable del proyecto
* `develop` → rama de integración
* `feature/motor-core` → lógica principal del motor
* `feature/avanzadas` → funcionalidades avanzadas
* `feature/documentacion` → documentación completa y README extendido

---
